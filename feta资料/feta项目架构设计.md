# feta项目架构设计

```
┌────────────────────────────────────────────────────────────────────────────────────────────┐
│                           1. 展示与交互层  (Presentation Layer)                            │
│                       App: Streamlit Web UI  (app/streamlit_app.py)                        │
│                                                                                            │
│  · 接收用户输入的社交博文                                                                  │
│  · 展示后台预测的心理画像（Demo 调试视角：风险等级、诱因标签）                             │
│  · 展示正向无痕推荐 Feed 流（Top-K 疏导博文）                                              │
└────────────────────────────────────────────────────────────────────────────────────────────┘
                                               │
                                               ▼  调用 pipeline.py (主流程入口)
┌────────────────────────────────────────────────────────────────────────────────────────────┐
│                          2. 核心业务与流水线层  (Pipeline Layer)                           │
│                                 Pipeline:  src/pipeline.py                                 │
│                                                                                            │
│  · 协调各模块顺序执行：预处理 → NLP 特征与画像渲染 → 向量提取 → 推荐匹配                   │
└────────────────────────────────────────────────────────────────────────────────────────────┘
                ┴──────────────────────────────┬──────────────────────────────┴               
                │                              │                              │               
                ▼                              ▼                              ▼               
┌──────────────────────────────┬──────────────────────────────┬──────────────────────────────┐
│   3.1 NLP 心理感知与画像层   │    3.2 向量 Embedding 层     │     3.3 召回与精排推荐层     │
│     (src/classifier.py)      │      (src/embedder.py)       │     (src/recommender.py)     │
│                              │                              │                              │
│· 文本清洗 (src/preprocess.py)│· 模型: all-MiniLM-L6-v2      │· 风险断路器: 高风险降级为热线│
│· 风险分类与D1-D4情感特征提取 │· 输入: 用户心理画像 Prompt   │· 诱因硬/软过滤 (Target Cause)│
│· 心理诱因多标签识别(容貌焦虑)│· 输出: 384维稠密向量         │· Cosine 相似度与多因子加权   │
│· 输出结构化 Prompt 渲染画像  │       (User Vector)          │· 最终输出 Top-K 正向推荐列表 │
└──────────────────────────────┴──────────────────────────────┴──────────────────────────────┘
                                                                              ▲               
                                                                              │                 预计算 Embedding 并加载
┌────────────────────────────────────────────────────────────────────────────────────────────┐
│                               4. 数据与资源层  (Data Layer)                                │
│                                                                                            │
│  · 原始数据: Sentiment140 正向推文(target=4) + Student Stress 数据集策略提取               │
│  · 核心资产 (data/interventions.csv): 增强博文、target_issue 标签、预计算向量              │
│  · 模型配置 (configs/config.yaml): 权重参数、阈值与模型路径                                │
└────────────────────────────────────────────────────────────────────────────────────────────┘
```
